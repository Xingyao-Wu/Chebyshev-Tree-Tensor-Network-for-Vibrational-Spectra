# Reference Data

This directory stores reusable reference spectra generated by
`CH3CN_reference_20dim.ipynb`.

Run the export cell in that notebook after computing the spectrum. It writes:

- `CH3CN_reference_20dim_latest.npz`
- `CH3CN_reference_20dim_basis_<N>.npz`

Quick load:

```python
import numpy as np

ref = np.load("/Users/link/Desktop/A_Python_code/Chebyshev/reference/CH3CN_reference_20dim_latest.npz")
E_grid = ref["E_grid"]
vals_ref = ref["vals_ttns_eff"]
```

Or:

```python
from reference import load_ch3cn_reference_20dim

ref = load_ch3cn_reference_20dim()
E_grid = ref["E_grid"]
vals_ref = ref["vals_ttns_eff"]
```
